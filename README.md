# Shtabel — a yard system for small container terminals

Shtabel is a learning project: a simple terminal operating system (TOS) for a container terminal that runs in the browser on a computer or a phone. This is a demo version: all data is fictional and resets when you reload the page.

It is built for small terminals and dry ports with a steady flow of containers. Large TOS products are too expensive for them, and Excel is no longer enough.

Features: container gate-in and gate-out with ISO 6346 number check, a yard map by blocks, rows and tiers, wagons on tracks with train arrival from Excel, storage charges by tariff, general cargo, extra services with acts, a forwarder portal and Excel reports.

**Demo:** https://maksat-star.github.io/yard-tos/

# Штабель — учёт для небольшого контейнерного терминала

Штабель — учебный проект: простая система учёта (TOS) для контейнерного терминала, которая работает в браузере на компьютере и телефоне. Сейчас это демо-версия: данные вымышленные и сбрасываются после перезагрузки страницы.

Проект рассчитан на небольшие терминалы и сухие порты со стабильным потоком контейнеров. Большие TOS-системы для них слишком дорогие, а в Excel вести учёт уже неудобно.

Что умеет: приём и выдача контейнеров с проверкой номера по ISO 6346, схема площадки по блокам, рядам и ярусам, вагоны на путях и приём состава из Excel, расчёт хранения по тарифам, генгруз, доп. услуги с актами, кабинет экспедитора и отчёты в Excel.

**Демо:** https://maksat-star.github.io/yard-tos/
